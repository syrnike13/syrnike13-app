# ADR-0009 — Лендинг и приложение разведены по доменам

- **Status:** Accepted
- **Date:** 2026-10-20

## Контекст

Лендинг и веб-клиент собирались одним TanStack Start приложением
(`apps/web`) и отдавались с одного домена `syrnike13.ru`. Из-за этого:

- правки маркетинговой страницы пересобирали клиент и наоборот;
- клиентские ассеты требовали специальных Caddy-маршрутов
  (`/app/assets*`, `/app/manifest.webmanifest`);
- домен приложения и публичный домен API/скачиваний были одним и тем же.

## Решение

- Лендинг вынесен в самостоятельное Vite-приложение `apps/landing`
  со своим Docker-образом `app-landing`.
- Публичные адреса:
  - `https://syrnike13.ru` — лендинг и загрузки;
  - `https://app.syrnike13.ru` — веб-клиент, `/invite/*`, `/login/*`, `/m/*`.
- Клиент живёт в корне app-домена. Desktop-маршруты перенесены из
  `routes/app/*` в pathless layout `routes/_app/*`, поэтому URL больше не
  содержит `/app`.
- Старые ссылки `syrnike13.ru/app/*`, `/m/*`, `/login/*`, `/invite/*`
  редиректятся Caddy на app-домен с сохранением пути и query.
- Invite-ссылки и ссылки на сообщения строятся от `VITE_PUBLIC_APP_URL`
  (по умолчанию `https://app.syrnike13.ru`).
- Desktop хранит отдельно `appHost` (веб-клиент и deep links) и `publicHost`
  (API, WS, media, downloads). Старые deep links на общем домене продолжают
  приниматься.
- Nightly: лендинг на `beta.syrnike13.ru`, приложение на
  `app.beta.syrnike13.ru`.

## Последствия

- Нужны DNS-записи и TLS для app-домена в production и nightly.
- Пользователи один раз войдут заново: `localStorage` привязан к origin, поэтому
  сессия, тема, язык и push-подписка со старого домена не переносятся.
- Аутентификация не затрагивается: сессия хранится в `localStorage` клиента,
  API остаётся на основном домене.
- Нужно добавить app-домен в настройки hCaptcha и другие внешние allowlist'ы.
- Cache/service worker живут на app-домене; на старом домене остаётся
  kill-switch `sw.js`, который снимает старую регистрацию.
- Лендинг больше не использует общий Prism-контекст приложения: тёмная тема
  выбирается по системной настройке, а цвета берутся из дефолтной темы.
