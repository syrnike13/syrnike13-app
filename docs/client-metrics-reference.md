# Client metrics reference

Целевые метрики клиента, снятые через Chrome DevTools Protocol 2026-10-18.
Условия замера: Chrome 155, окно 1920×945, тема dark, плотность `density-default`
(cozy), `font-size-16`, locale ru. Значения — computed styles реальных элементов,
а не догадки из скриншотов. Вёрстка эталона меняется между релизами: при
расхождении перемеряйте, а не подгоняйте код под устаревшую цифру.

Эталонный шрифт проприетарный. Совпадать имеет смысл с размерами,
межстрочными интервалами и геометрией, а не с файлом шрифта.

## Как это соотносится с syrnike13

Значения syrnike13 — из `packages/ui/src`, `apps/web/src` и `apps/admin/src`
на момент замера.

### Совпадает

Shell выровнен по живым метрикам эталона:

- сетка 4px (`--spacing: 0.25rem`), rail 72px, иконка 40px, gap 8px, верхний отступ 0;
- колонка каналов 304px (эталон 303px; 1px оставлен, чтобы вместе с member list
  264px контент был ровно 1280px);
- шапка колонки 49px, padding 8px, имя сервера 16/20 w600;
- строка канала 32px, шаг 34px, padding 4/8, radius 8px, icon 20px, текст 16/24,
  w500 у всех каналов;
- категория: блок 40px, текст 14/18 w500, отступ 16px, шеврон 12px справа,
  без принудительного uppercase; отступ между категориями даёт сама категория;
- баннер сервера 130px, шапка 49px поверх, при скролле уезжает на 90px и
  гаснет за 88px;
- member list 264px;
- плавающие панели: inset 8px, высота 58px (56px + ring), bottom 8px,
  охват rail+sidebar, radius 8px;
- user panel: padding 12px, avatar 32px, имя 16/18 w500, статус 12/13 w500,
  controls 32px, split 49px, gap 8px;
- композер: 1264×58px, editor min-height 56px, padding 17px 0, 16/22,
  buttons 32px/icon 20px, внутренний inset 12px;
- title bar web и Electron Windows 32px;
- сообщение 16/22, timestamp 12/22, avatar 40px, member avatar 32px,
  group start 17px, автор w500;
- лента на `MessageScroller`: автопрокрутка у нижней границы, сохранение
  позиции при подгрузке истории, divider «Новые сообщения» и кнопка
  «К последним»; изображения резервируются по метаданным (550×350 max);
- группировка одного автора рвётся после 7 минут; hover-панель 28px;
- профили: поповер 300px с баннером 105px и аватаром 80px, имя 20/24 w600,
  роли 24px; модалка 962×800 с левой карточкой 400px, баннером 140px,
  аватаром 120px, именем 24/32 w600 и секциями 12/16 w500; общие друзья
  и серверы, «Полный профиль», меню действий и подтверждение блокировки.

| Параметр | syrnike13 | Эталон | Причина |

| Вес названия канала | 500 у всех | 400, у выбранного — 500 | По решению продукта вес не меняется от активности |
| Трекинг подписей | -0.025em (`tracking-tight`) | normal | Nunito Sans шире шрифта эталона; так ширина строк совпадает |
| Иконка сервера в шапке | нет | 18px | По решению продукта |

### Что осталось из старых различий

- Общая шкала радиусов примитивов и размеры Button/Input/Textarea.
- Правый блок кнопок композера.
- Glyph рельса 18 vs 24.
- Разделитель после системного блока (появится вместе с ним).

Миграция на примитивы выполнена: `Command` (палитра и поиск), `Sheet` (мобильные
настройки), `DropdownMenu` (меню сервера и статусы), `ToggleGroup` (режим темы),
`RadioGroup` (фильтры и статусы), `NativeSelect` (нативные селекты),
`Checkbox` (выбор участников), `Tabs` (админка), `Spinner`, `Skeleton`,
`Empty` и `Separator` заменили самописные варианты. Shell, колонка каналов,
user panel, лента сообщений, композер и профили выровнены по эталону.

## Линтер

Правила дизайна, их назначение и исключения описаны в `packages/ui/AGENTS.md`
(раздел «Линтер дизайна»); команда — `pnpm lint:design`, без baseline.

  `tv` — встроенная функция tailwind-variants, и линтер принимал ключи
  переводов за классы.
