# Windows media engine v2

This package is the empty ownership boundary for the replacement Windows native media engine. It intentionally contains no production engine code, native sources, media dependencies, or compatibility layer over the removed v1 implementation.

`pnpm --filter @syrnike13/windows-media-engine build` is a placeholder check. Implementation starts only after the architecture, release bar, and resource ownership rules in `docs/native-v2/` are accepted.
