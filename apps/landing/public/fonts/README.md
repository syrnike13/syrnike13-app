# Application fonts

Nunito Sans (normal and italic, weights 400–900) and Space Grotesk (weights
500–700) are served locally so an unavailable Google Fonts stylesheet cannot
block application startup. All supplied language subsets and `font-display:
swap` are retained. The WOFF2 files are unmodified Google Fonts downloads.

`sources.json` records each upstream URL, SHA-256 and byte length. The two
`*-OFL.txt` files contain the authors' copyright notices and SIL Open Font
License 1.1 and are distributed with the fonts.
